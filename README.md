# HNY 2026 

Happy New Year 2026 Celebration App 🎆
A beautiful animated celebration application with fireworks, confetti, and music, built using Python and Tkinter.

✨ Features
🎆 Realistic Fireworks - Multiple explosion patterns (circle, star, heart, double)
🌟 Twinkling Stars - Animated starry background
🎊 Floating Confetti - Colorful confetti falling
💫 Glowing Text - Rainbow cycling "Happy New Year 2026"
🖱️ Interactive - Click to launch fireworks anywhere
⏱️ Countdown Mode - Optional countdown timer

Requirements
- Python 3.x
- Tkinter (built-in)
- Random, math, time, datetime, threading (built-in)

Usage
1. Run python celebration.py (or your script name)
2. Choose start mode:
    - 1: Direct Celebration
    - 2: 10-Second Countdown
3. Controls:
    - Click anywhere to launch fireworks
    - Press SPACE for firework burst
    - Press ESC to exit

Code Structure
- Particle class: represents a single particle (firework/confetti)
- Firework class: represents a firework that launches and explodes
- NewYearCelebration class: main application class
- CountdownWindow class: optional countdown window
