# HNY 2026 

Happy New Year 2026 Celebration App 🎆
A beautiful animated celebration application with fireworks, confetti, and music, built using Python and Tkinter.

Features- 🎆 Animated fireworks and confetti
- 🎉 Music and sound effects
- 🌟 Twinkling stars and gradient background
- 📅 Countdown to New Year (optional)
- 🖱️ Interactive controls (click, space, ESC)

Requirements- Python 3.x
- Tkinter (built-in)
- Random, math, time, datetime, threading (built-in)

Usage1. Run python celebration.py (or your script name)
2. Choose start mode:
    - 1: Direct Celebration
    - 2: 10-Second Countdown
3. Controls:
    - Click anywhere to launch fireworks
    - Press SPACE for firework burst
    - Press ESC to exit

Code Structure- Particle class: represents a single particle (firework/confetti)
- Firework class: represents a firework that launches and explodes
- NewYearCelebration class: main application class
- CountdownWindow class: optional countdown window

Notes- This code is for educational purposes only.
- Customize and extend as needed! 🎉
